Produce a decision-useful, source-backed deep research report for the bound project.

Start with the run's `question`. Read the durable project checkout before searching so the report
does not repeat work already present and so assumptions are attributed to project evidence rather
than invented. Use current web search for external facts, prefer primary and authoritative sources,
and follow important claims back to their original source when possible.

Research top-down: test the most fundamental assumptions before spending time on downstream market,
commercial, or execution questions. If a foundational assumption fails, say so clearly and narrow
or stop the lower-level analysis. Distinguish sourced findings, project claims, and your own
inferences. Never fill a gap with a plausible-sounding fact.

The final Markdown artifact must stand on its own. It should give the direct answer first, record
what changed or was contradicted, explain the implications for the project, identify genuine
unknowns, and include working source links near the claims they support. Do not create another file,
publish externally, contact anyone, or ask an interactive question; unresolved choices belong in the
report for the founder to review.
